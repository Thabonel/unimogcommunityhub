## Q11: How do you replace wheel hub seals on the portals?

**Section**: Section 33: Front Axle (pages 381-410)
**Pages Found**: Pages 524-525, 547

**Barry's Answer:**

Wheel hub seal replacement on portal axles requires special tools and procedures:

1. **Special Tools Required**:
   - Tool No. 2: Allan key socket 14 mm (3/4" square) for brake disk - Ref: 001 589 68 09 00
   - Tool No. 3: Allan key socket 17 mm (3/4" square) for wheel hub - Ref: 001 589 69 09 00
   - Tool No. 5: Guide pins (2 required) for proper alignment
   - Extension tube for mounting flange - Ref: 000 589 01 14 00

2. **Seal Location and Type**:
   - Wheel hub drive seals prevent oil leakage from portal gearbox
   - Located on both front and rear wheel hubs
   - Different seals for different axle models (737.2, etc.)

3. **Disassembly Procedure**:
   - Remove wheel and tire assembly
   - Remove brake components as needed
   - Drain oil from wheel hub drive
   - Remove fastening bolts using proper socket tools
   - Extract hub assembly with seals

4. **Seal Installation**:
   - Coat pinion bearing surfaces with running-in paste No. 7
   - Install seals with proper orientation
   - Use shim rings determined on dimension sheet
   - Install 0-ring in axle housing
   - Ensure oil duct faces upward

5. **Reassembly**:
   - Coat torque tube flange with sealing compound No. 1
   - Bolt torque tube to pinion flange
   - Install wheel hub drive with new seals
   - Tighten all fasteners to specification
   - Refill with specified gear oil

6. **Torque Specifications**:
   - Specific torques listed in Section 33.3 data sheets
   - Different specifications for various axle configurations
   - Preload settings for tapered roller bearings critical

**Important**: Always use the dimension sheet specific to your axle configuration - seal specifications vary by model.

## Q15: How do you remove and install the transmission assembly?

**Section**: Section 26.13: Main Transmission (pages 207-270)
**Pages Found**: Pages 207, 208, 250

**Barry's Answer:**

Transmission removal and installation is a major procedure requiring proper support and sequence:

1. **Preparation and Safety**:
   - Raise cab using proper procedure (60.5-2.1/1 or 60.5-2.2/1)
   - Remove spare wheel and metal covers
   - Install safety supports - transmission is heavy
   - Drain transmission oil into proper container

2. **Component Disconnection**:
   - Remove input shaft assembly
   - Disconnect shift linkage completely
   - Remove speedometer shaft with seating sleeve
   - Remove shift gate indicator
   - Disconnect backup lamp switch
   - Disconnect shift valve pneumatic line

3. **Main Transmission Removal Steps**:
   - Support transmission with proper jack
   - Remove fastening bolts in correct sequence
   - Carefully lower transmission to work surface
   - Remove from under vehicle with help

4. **Installation Sequence**:
   - Support transmission on proper jack
   - Align with engine output flange
   - Guide input shaft into clutch assembly
   - Install fastening bolts in cross pattern
   - Tighten to specification gradually

5. **Component Reconnection**:
   - Attach shift linkage and verify adjustment
   - Install speedometer shaft with proper seating
   - Connect all electrical switches and plugs
   - Attach pneumatic lines (ensure proper connections)
   - Connect shift valve line with proper torque

6. **Final Steps**:
   - Fill transmission with specified oil grade (refer to capacities)
   - Check all connections for security
   - Lower cab carefully into position
   - Test shifting through all gears
   - Check for leaks before operation

7. **Contents Reference** (page 208):
   - Disassembly and assembly procedures (page 2)
   - Shifting shaft procedures (page 8)
   - Gear shift cover procedures (page 9)
   - Idler gear procedures (page 10)
   - Oil pump service (page 11)

**Transmission Designations**:
- UG 3/40-8/13.01 GPA (standard)
- UG 3/40-8/9.35 GPA (with additional working group)
- NG 3/40-3/55.87 (crawler group)
