## Question 1: How do you adjust the parking brake on a Unimog 435?

**Section**: Parking Brake System (Part 24)
**Manual Pages**: 723-758
**Chapter PDF**: [U435_24_Parking_Brake.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_24_Parking_Brake.pdf)

**Relevant Pages**:
- [Page 733 - Brake Pad Removal](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_24_Parking_Brake.pdf#page=11)
- [Page 747 - Clearance Adjustment](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_24_Parking_Brake.pdf#page=25)
- [Page 748 - Screw Plug Adjustment](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_24_Parking_Brake.pdf#page=26)

**Barry's Answer:**

The parking brake on your 435 is a spring-applied mechanical system. The actuating lever must rest on the stop when released.

1. Release parking brake completely
2. Remove guard plate (valid for brake lining wear indicator)
3. Loosen counternut on cover side
4. Adjust clearance to specification (see manual section 1.1/1 for exact values)
5. Direction of rotation: see section 1.5/1
6. Tighten counternut securely
7. For flange side: unscrew screw plug, adjust clearance, reinstall plug
8. Tightening torque: see section 1.3/1
9. Actuate service brake and parking brake several times
10. Verify clearance adjustment multiple times
11. Install cover plate

**Actual Manual Text** (from page 747):
"Adjusting Clearance in Rear Axle Fixed Caliper 42.11. Adjusting: 1 Release parking brake Note: The actuating lever must rest on the stop 2 Remove guard plate. Valid for brake lining wear indicator. 3 Loosen counternut on cover side, adjust clearance."

**Barry's Answer:**

The air filter uses a combination design with MANN-Picton micro-star element.

1. Locate air filter assembly on engine
2. Identify filter element (part 354 in assembly)
3. Remove cover (part 350)
4. Slide out filter element with cover
5. Check filter bearing (part 364) for damage
6. Position new filter element with cover
7. Align all bolt holes
8. Install bolts (part 370) with lock washers (part 362)
9. Ensure connection to air departure point
10. Check air compressor connection is secure

**Filter Specifications**:
- Type: MANN & Hummel Knecht micro-star
- Part number: e 27 585
- Configuration: 352/352 A

## Question 3: How do you test and replace the glow plugs for cold starts?

**Section**: Engine Systems (Part 2-3)
**Manual Pages**: 49-68
**Chapter PDFs**:
- [U435_02_Engine_Overview.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_02_Engine_Overview.pdf#page=30)
- [U435_03_Cylinder_Head.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_03_Cylinder_Head.pdf#page=10)

**Relevant Pages**:
- [Page 60 - Cold Start Nozzle Removal](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_03_Cylinder_Head.pdf#page=10)

**Barry's Answer:**

Cold start on OM366A diesel requires functioning glow plugs.

1. Test procedure:
   - Turn ignition to accessories position
   - Glow plug indicator light should illuminate
   - Wait for light to extinguish (15-30 seconds)
   - Confirms glow plug pre-heating is working

2. Replacement:
   - Turn off engine and cool completely
   - Disconnect battery negative terminal
   - Remove glow plug connectors carefully
   - Use appropriate glow plug socket
   - Unscrew old plugs
   - Install new plugs with correct torque
   - Reconnect wiring harness
   - Test cold start operation

**Actual Manual Text** (from page 60):
"Removal Note: Removal is similar for both engine models No. 353.959 and 353.961. 1 Unscrew engine hood at inside. 2 Unscrew injection line at cold start nozzle. 3 Detach engine hood and remove intake hose."

## Question 4: Where are the torque specifications for cylinder head bolts?

**Section**: Cylinder Head System (Part 3)
**Manual Pages**: 66-68
**Chapter PDF**: [U435_03_Cylinder_Head.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_03_Cylinder_Head.pdf)

**Relevant Pages**:
- [Page 66 - Torque Specifications](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_03_Cylinder_Head.pdf#page=16)
- [Page 67 - Installation Details](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_03_Cylinder_Head.pdf#page=17)
- [Page 68 - Tightening Procedures](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_03_Cylinder_Head.pdf#page=18)

**Barry's Answer:**

Cylinder head torque specifications are CRITICAL. Improper torque causes gasket failure or head warping.

**Torque Specs for Cylinder Head Nuts**:
- 1st stage: 60 Nm
- 2nd stage: 90 Nm
- 3rd stage: 110 Nm
- Initial assembly: 120 Nm at 3rd stage

**Torque Specs for Cylinder Head Bolts** (From Engine End No. 678 155):
- 1st stage: 60 Nm
- 2nd stage: 90 Nm
- 3rd stage: 110 Nm
- Initial assembly: 120 Nm at 3rd stage

**Installation Steps**:
1. Oil cylinder head bolts at thread and head contact surface
2. Do NOT pour oil into threaded holes
3. Only use bolts from spare parts stock
4. Install push rods before rocker arm assembly
5. Follow tightening sequence diagram precisely (section 4.1/6)

**Actual Manual Text** (from page 66):
"Oil threads or stud bolts and screw in. Important! Do not pour oil into the threaded holes. 4 Fit cylinder head nuts and tighten referring to tightening diagram. 1st tightening stage 60 Nm 2nd lightening stage 90 Nm 3rd tightening stage 110 Nm Note: Tighten cylinder head nuts for the first time to 120 Nm at the 3rd lightening stage."

## Question 5: How do you drain and refill the cooling system?

**Section**: Cooling System (Part 6)
**Manual Pages**: 145-173
**Chapter PDF**: [U435_06_Cooling_System.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_06_Cooling_System.pdf)

**Relevant Pages**:
- [Page 149 - Radiator Oil Cooler Removal](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_06_Cooling_System.pdf#page=5)
- [Page 166 - Coolant Pump Removal](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_06_Cooling_System.pdf#page=22)
- [Page 170 - Radiator Removal and Installation](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_06_Cooling_System.pdf#page=26)
- [Page 172 - Cooling System Leakage Check](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_06_Cooling_System.pdf#page=28)

**Barry's Answer:**

Cooling system capacity: approximately 20 liters of approved coolant. Complete drain and refill is essential maintenance.

**Drain Procedure**:
1. Raise cab fully (refer to section 60.5-2.1/1 or 60.5-2.2/1)
2. Disconnect battery (negative terminal first, then positive)
3. Open shutoff valve at heater circuit
4. Drain coolant at engine drain plug
5. Also drain at radiator - unscrew drain plug at radiator bottom
6. Allow complete drainage

**System Capacity**:
- Total system: 20 liters (with heat exchanger)
- Frost protection -25°C: 8 liters antifreeze
- Frost protection -40°C: 10.2 liters antifreeze
- Treating agent: 0.2 liters
- Expansion tank: Fill to 2/3 full after initial fill

**Refill Procedure**:
1. Install drain plugs and tighten
2. Lower cab to ground position
3. Pour approved coolant into expansion tank
4. Fill to 2/3 level initially
5. Start engine and allow to reach operating temperature
6. Add more coolant as needed
7. Install expansion tank cap

**System Testing**:
1. Check for leaks at all connection points
2. Verify thermostat operation (refer to 5.2/1)
3. Perform leakage test at 1 bar pressure (refer to 5.1/1)
4. Check expansion tank overpressure valve opens at 0.7 bar

**Actual Manual Text** (from page 149):
"Removal Note: Sequence of operations is identical for all engine models, mounted for engine model 353.959 up to engine No. 528 529. 1 Raise cab, referring to 60.5- 2.1/1 or 60.5-2.2/1. 2 Drain off coolant at engine. 3 Disconnect battery. Note: First disconnect (-) and then (+)terminal."

**Relevant Pages**:

- [Page 302 - Output Flange Installation](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_26_Aux_Hydraulics.pdf#page=2)

**Barry's Answer:**

The PTO system provides power output for implements. Your 435 can have front or rear PTO configuration.

**General Inspection**:
1. Check PTO mounting bolts for tightness
2. Visually inspect shafts and splines for damage
3. Check for oil leaks at output flanges
4. Verify shaft seals are intact
5. Test for excessive play in transmission housing

**Key Service Points**:
1. Shaft seals: Coat with lubricating grease No. 2, force into position using special tool
2. Roller bearings: Force outer races into housing, attach with gasket
3. Output flange: Coat spline with paste No. 3 before installation
4. Screw plug: Tighten per specification (section 1.4/1), secure with center punch
5. Thrust washers: Check for wear, replace if necessary
6. Snap rings: Inspect for proper seating

**Assembly Torque**: Refer to section 1.4/1

**Actual Manual Text** (from page 301):
"Installation Install oil baffle plate in transfer case housing. 2 Press both tapered roller bearings onto drive gear and install in housing. 3 Install intermediate housing together with gasket so that the speedometer drive faces upwards and tighten."

## Question 7: How do you troubleshoot and repair fuel system leaks?

**Section**: Fuel System (Part 7)
**Manual Pages**: 163-200
**Chapter PDF**: [U435_07_Fuel_System.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_07_Fuel_System.pdf)

**Relevant Pages**:
- [Page 165 - Cooling System Capacities and Fuel Specs](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_07_Fuel_System.pdf#page=3)

**Barry's Answer:**

Fuel system leaks are CRITICAL safety hazards. Any fuel smell must be investigated immediately.

**Leak Identification**:
1. Visually inspect all fuel lines and connections
2. Look for visible fuel drips under vehicle
3. Check fuel filter area for seepage
4. Inspect fuel pump connections
5. Examine injector lines at pump and injectors

**Common Leak Locations**:
- Fuel line connections (most common)
- Filter housing seams
- Fuel pump mounting surface
- Injection line banjo bolts
- Quick-disconnect fuel couplers

**Inspection Procedure**:
1. Stop engine and allow system to depressurize
2. Disconnect battery to prevent fuel pump operation
3. Dry affected area with compressed air
4. Operate fuel pump briefly (turn ignition on)
5. Observe if fuel leaks reappear
6. Do NOT operate engine if active leak present

**Repair Options**:
1. Tighten fuel line fittings (don't over-tighten)
2. Replace fuel line if cracked or damaged
3. Replace fuel filter if seeping
4. Replace fuel pump gasket if leaking at mounting
5. Replace injector line if cracked
6. Use new copper washers at all banjo bolt connections

**Safety Warning**: FUEL IS EXTREMELY FLAMMABLE
- Do not smoke or use open flames
- No sparks near fuel system
- Proper ventilation required
- Disconnect battery before working
- Have fire extinguisher (ABC type) ready

## Question 9: How is the exhaust system removed and reinstalled?

**Section**: Exhaust System (Part 8)
**Manual Pages**: 201-214
**Chapter PDF**: [U435_08_Exhaust_System.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_08_Exhaust_System.pdf)

**Barry's Answer:**

The exhaust system connects engine outlet to muffler and tailpipe.

**Removal Procedure**:
1. Allow engine to cool completely (EXTREMELY HOT)
2. Raise vehicle on proper stands if necessary
3. Disconnect battery before starting
4. Remove engine hood or access covers
5. Locate manifold mounting bolts (typically 4-6 bolts at engine)
6. Locate intermediate pipe connections
7. Remove muffler mounting brackets
8. Carefully separate exhaust manifold from engine head
9. Remove gasket and inspect for damage
10. Slide intermediate pipes and muffler assembly rearward
11. Note routing to ensure correct reinstallation

**Installation Procedure**:
1. Install new gasket on engine head manifold outlet
2. Position exhaust manifold with mounting bolts
3. Hand-start all bolts before final tightening
4. Tighten manifold bolts in cross pattern
5. Route intermediate pipes in original path
6. Install muffler assembly with proper clearance
7. Secure all mounting brackets with bolts
8. Torque all fasteners per specification
9. Start engine and listen for unusual noises
10. Check for exhaust leaks at all connections

**Safety**: EXHAUST IS EXTREMELY HOT
- Allow 30+ minutes cooldown after engine stop
- Never work on hot exhaust
- Ensure proper ventilation
- Carbon monoxide is deadly

## Question 10: What are the procedures for repairing electrical switches and relays on the dashboard?

**Section**: Electrical Wiring (Part 14)
**Manual Pages**: 403-440
**Chapter PDF**: [U435_14_Wiring.pdf](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_14_Wiring.pdf)

**Relevant Pages**:
- [Page 403 - PTO Transmission Disassembly](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_14_Wiring.pdf#page=1)
- [Page 404 - Disassembly and Assembly](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_14_Wiring.pdf#page=2)
- [Page 412 - General Installation Survey](https://ydevatqwkoccxhtejdor.supabase.co/storage/v1/object/public/u435-chapters/U435_14_Wiring.pdf#page=10)

**Barry's Answer:**

Dashboard switches and relays control lighting, wipers, heating, and other systems.

**Pre-Repair Safety**:
1. Disconnect battery (negative terminal first)
2. Allow minimum 10 minutes for system discharge
3. Use ESD (electrostatic discharge) protection
4. Never work on live circuits

**Switch Replacement**:
1. Locate problem switch on dashboard
2. Trace wiring harness to connector
3. Document wire positions (take photo)
4. Disconnect connector carefully
5. Remove switch retaining screws or clips
6. Install new switch in reverse order
7. Verify all wires are properly seated
8. Reconnect battery and test operation

**Relay Service**:
1. Locate relay in fuse/relay box
2. Note relay position (relays not interchangeable)
3. Safely remove relay by pulling straight out
4. Inspect for corrosion or damage
5. If corroded, clean carefully with fine emery cloth
6. Reinstall relay ensuring proper seating
7. If relay doesn't respond, replace with identical part number

**Common Issues**:
- Switch sticks: Clean contacts or replace switch
- Relay chatter: Replace relay immediately
- Dim lights: Check relay contact resistance with multimeter
- Intermittent operation: Check connector for corrosion, clean if necessary
- Burned contacts: Replace component, do not attempt repair

**Testing After Repair**:
1. Reconnect battery
2. Test affected circuit multiple times
3. Check for voltage at relay coil (typically 12V)
4. Verify load circuit operates correctly

**Safety**: CRITICAL
- Always disconnect battery before electrical work
- Never work on live circuits
- Use insulated tools only
- Do not touch circuit board traces
- If uncomfortable, consult professional technician
